# Official patchcord wire colors

These are the solid-color wire spools available for patchcord assembly.
PatchCordHelper assigns only these colors to generated wires. Source YAML
colors are preferences; a stripe, unavailable color, or missing color is
replaced with an available solid color. Within an assembly step, each color
appears on at most one wire. The helper creates another step when needed.

- white
- black
- red
- orange
- yellow
- green
- blue
- grey
- brown
